# NBM Update Discovery v1.2.3 주요 업데이트

`v1.2.3`은 지도 기반 관심지역 내보내기, 폴리곤 다중 선택과 형태 편집 저장, 좌표계와 처리 히스토리 표시를 개선한 릴리스다.

## 사용자 기능

| 구분 | 변경 내용 |
|---|---|
| 관심지역 내보내기 | 내보내기 팝업 지도에서 원형·다각형·자유형·사각형 영역을 지정하고 해당 영역과 교차하는 객체만 내보낸다. |
| 지도 배경 | 과년도·당해년도 정사영상 전환, 영상별 영역, 변화탐지 처리영역을 표시한다. |
| 지원 형식 | SHP, 2D DXF, 3D DXF, PDF에 동일한 관심지역 객체 목록을 적용한다. |
| 다중 선택 | 선택 모드에서 `Shift+드래그`로 폴리곤을 추가 선택할 수 있다. |
| 형태 편집 | 꼭짓점 이동·추가·삭제 완료 직후 저장하고 선택 모드로 복귀한다. |
| 좌표계 | `TM 중부 (EPSG:5186)`처럼 짧고 일관된 이름을 표시한다. |
| 처리 히스토리 | `생성`·`삭제`·`수정`·`의견`, 객체 종류, 변화유형, `obj_id`, 처리의견, 시각을 한 줄로 표시한다. |

## 처리 히스토리 호환성

`v1.2.2`까지 객체 종류 또는 변화유형 변경은 내부적으로 `edit_meta`로 저장됐다. `v1.2.3`은 새 변경부터 `classify`로 구분하지만, 기존 `edit_meta` 이력을 자동 변환하지 않는다.

따라서 이전 프로젝트의 과거 분류 변경 이력이 `의견`으로 표시될 수 있다. 이는 표시 분류 문제이며 기존 객체, 폴리곤, 의견 또는 DB 데이터가 변경되거나 삭제되는 문제는 아니다.

## 배포 영향

- DB migration 추가 없음
- PostgreSQL, Redis, storage named volume 구조 변경 없음
- PM submodule 및 모델 가중치 변경 없음
- Compose 서비스와 외부 `HOST_*` 경로 구조 변경 없음
- 관심지역 SHP 내보내기는 신규 백엔드 POST API를 사용하므로 프런트엔드와 백엔드를 반드시 같은 `v1.2.3` 패키지로 업데이트해야 함

## 설치 후 확인

1. 기존 프로젝트와 객체 수가 유지되는지 확인한다.
2. 관심지역 네 가지 그리기 도구와 전체 결과 내보내기를 확인한다.
3. SHP·DXF·3D DXF·PDF가 선택된 객체 수와 일치하는지 확인한다.
4. `Shift+드래그` 다중 선택과 일괄 삭제를 확인한다.
5. 꼭짓점 변경 후 처리 히스토리에 `수정`이 생성되는지 확인한다.
6. 처리의견 저장 후 처리 히스토리에 `의견`과 의견 내용이 표시되는지 확인한다.

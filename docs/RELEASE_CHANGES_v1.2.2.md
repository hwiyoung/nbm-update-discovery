# NBM Update Discovery v1.2.2 주요 업데이트

이 문서는 NBM Update Discovery 공식 Git 태그 `v1.2.0`, `v1.2.1`, `v1.2.2`의 주요 기능과 실제 변경 범위를 요약한다.

## 1. 버전별 요약

| 버전 | 릴리스 성격 | 주요 내용 |
|---|---|---|
| `v1.2.0` | 첫 번째 정식 릴리스 | 분할 화면 개선, 영상 바운더리, 다중 영상 처리, UTF-8 SHP, 변화탐지 재실행 안정화 등 주요 운영 기능 포함 |
| `v1.2.1` | 오프라인 배포 개선 | 앱·Docker 이미지와 모델을 분리한 패키지, checksum, 자동 설치·검증 스크립트 추가 |
| `v1.2.2` | 프론트엔드 오류 수정 | 도로 수동 편집에서 엔진이 지원하지 않는 `갱신(road_updated)` 옵션 제거 |

## 2. 주요 업데이트 목록

1. 과년도·당해년도 분할 화면 가시성 개선
2. 과년도·당해년도 영상 바운더리 표시
3. SHP 데이터 한글 인코딩 문제 해결
4. 프로젝트 생성 시 다중 영상 선택 및 처리
5. 변화탐지 연속 처리 시 비정상 재실행 방지
6. 완전 오프라인 배포 패키지 및 자동 설치 절차 추가
7. 도로 객체의 잘못된 `갱신(road_updated)` 선택 옵션 제거

## 3. 주요 기능 상세 비교

| 번호 | 업데이트 항목 | 적용 내용 | v1.2.0 | v1.2.1 | v1.2.2 |
|---:|---|---|:---:|:---:|:---:|
| 1 | 분할 화면 가시성 개선 | 왼쪽에 과년도, 오른쪽에 당해년도 영상을 표시하고 두 지도의 이동·확대/축소를 동기화한다. 다중 영상도 각 그룹에 함께 표시한다. | 포함 | 포함 | 포함 |
| 2 | 영상 바운더리 표시 | 과년도·당해년도 원본 영상의 footprint 외곽선과 실제 공통 처리영역 외곽선을 지도에 표시한다. | 포함 | 포함 | 포함 |
| 3 | SHP 인코딩 해결 | 백엔드 Fiona/GDAL로 SHP ZIP을 생성하고 DBF를 UTF-8로 기록한다. `.cpg`와 EPSG:5186 좌표계 정보도 포함한다. | 포함 | 포함 | 포함 |
| 4 | 다중 영상 처리 | 과년도와 당해년도에 각각 여러 영상을 선택할 수 있다. 선택된 영상은 VRT로 결합한 후 변화탐지 입력으로 사용한다. | 포함 | 포함 | 포함 |
| 5 | 재실행 문제 해결 | 실행마다 새 Celery task ID를 사용하고 완료된 작업의 중복 전달과 이전 실행의 stale delivery를 차단한다. visibility timeout과 worker prefetch도 보강했다. | 포함 | 포함 | 포함 |
| 6 | 오프라인 배포 지원 | Docker 이미지, 앱, 모델을 오프라인 패키지로 제공하고 manifest·SHA-256·자동 설치·검증 스크립트를 추가했다. | 미포함 | 추가 | 포함 |
| 7 | 도로 `갱신` 옵션 제거 | 도로 수동 편집 목록에서 엔진이 지원하지 않는 `road_updated` 선택지를 제거해 신규 흰 화면 오류 발생 경로를 차단한다. | 미포함 | 미포함 | 수정 |

> **버전 분류 주의:** 1~5번은 `v1.2.0` 이후 새로 추가된 기능이 아니라 공식 `v1.2.0` 태그를 만들기 전에 이미 반영된 개선 사항이다. 6번은 `v1.2.1`, 7번은 `v1.2.2`에서 실제로 추가 또는 수정됐다.

## 4. v1.2.0 대비 v1.2.2 실제 변경

| 구분 | v1.2.0 | v1.2.2 | 운영 영향 |
|---|---|---|---|
| 배포 파일 | 표준 오프라인 배포 세트 없음 | 앱·이미지 패키지와 모델 패키지 분리 제공 | 외부 인터넷 없이 배포 가능 |
| 무결성 확인 | 표준 manifest/checksum 없음 | `PACKAGE_MANIFEST.json`, `SHA256SUMS`, `MODEL_SHA256SUMS` 제공 | 전송 중 파일 손상과 잘못된 모델·이미지 확인 가능 |
| Docker 이미지 준비 | 설치 PC에서 직접 build | 패키지의 이미지를 `docker load`로 적재 | 오프라인 환경에서 build나 pull 불필요 |
| 설치 순서 | 운영자가 Compose, migration, seed를 직접 실행 | `install-offline.sh`가 순서대로 자동 실행 | 설치 명령 누락과 초기 DB 오류 가능성 감소 |
| 설치 후 검증 | 항목별 수동 확인 | `verify-offline.sh`로 버전, 웹, Celery, GPU, 모델 확인 | 설치 성공 여부를 일관되게 판정 |
| 도로 수동 편집 | `신설`, `갱신`, `소멸` 표시 | `신설`, `소멸`만 표시 | 잘못된 `road_updated` 신규 생성 방지 |
| 기존 `road_updated` DB 행 | 상세 화면 오류 가능 | 자동 변환되지 않음 | 업데이트 전에 기존 행을 반드시 점검하고 정리 |

## 6. 업데이트 후 확인할 기능

1. 과년도·당해년도 분할 화면이 정상적으로 표시되는지 확인한다.
2. 두 화면의 이동과 확대·축소가 함께 동작하는지 확인한다.
3. 각 영상의 바운더리와 공통 처리영역이 지도에 표시되는지 확인한다.
4. 과년도·당해년도에 여러 영상을 선택해 프로젝트를 생성할 수 있는지 확인한다.
5. 변화탐지를 연속으로 실행했을 때 완료된 작업이 임의로 다시 실행되지 않는지 확인한다.
6. 내보낸 SHP 파일의 한글 속성과 EPSG:5186 좌표계가 정상인지 확인한다.
7. 도로 수동 편집 목록에 `신설`, `소멸`만 표시되는지 확인한다.
8. 기존 프로젝트 상세 화면이 흰 화면 없이 열리는지 확인한다.

# FEATURE_SPEC.md — B 시스템 (변화탐지 분석 플랫폼)

> 본 문서는 B 시스템 프론트엔드 코드에서 **기능과 화면 구조만** 추출한 명세입니다.  
> 시각 표현(색·폰트·간격·그림자)은 모두 제외하고, 변화탐지 플랫폼 신규 구축 시 사용 가능한 형태로 정리했습니다.  
> 도메인 용어는 가능한 범위 내에서 일반화했습니다 (B 시스템의 특화 용어 → 대응 일반 용어 표기).

**기술 스택 요약 (참고용)**
- React 18 + TypeScript + Vite
- 라우팅: react-router (HashRouter, `#/...` 경로)
- 상태관리: Zustand (페이지·모듈별 store 분리)
- 지도: OpenLayers (`ol`, `ol-ext`)
- 표: AG Grid Community
- 차트: Chart.js + react-chartjs-2 (도넛, 누적 막대)
- 알림: react-hot-toast
- 실시간 진행률: socket.io-client (분석 진행 폴링·이벤트)
- 다이얼로그: Radix UI (alert-dialog, dropdown, popover)

## 1. 화면 인벤토리 (Screen Inventory)

| # | 라우트 | 화면 명칭 (일반화) | 목적 |
|---|---|---|---|
| 1 | `/` | **랜딩 페이지** | 시스템 소개 + 작업(분석) 목록 카드 그리드 진입점 |
| 2 | `/analyses` | **작업 목록 + 지도** (분석 목록) | 진행/완료된 변화탐지 작업을 지도 위치와 함께 탐색·진입 |

- 알림 다이얼로그 (벨 클릭 시 표시)
- 사이드바 토글 (좌측 패널 열고 닫기, 토글 상태 localStorage 영구화)
- 지도 컨트롤러 (베이스맵 전환, 줌 +/−, 거리 측정, 면적 측정)

## 2. 화면별 명세

### 2.1 랜딩 페이지 (`/`)

**사용자 목적**: 시스템에 처음 진입한 사용자가 시스템의 가치 제안을 인지하고, 기존 작업 목록을 카드 그리드로 둘러보다가 새 분석을 시작하기 위해 리소스 목록 화면으로 이동하는 것.

**레이아웃 영역** (수직 스택, 단일 컬럼)
- **상단 (헤더 띠)**: 글로벌 헤더 — 좌측 로고 + 버전 표시, 중앙 네비게이션 ("작업 목록" / "분석 생성"), 우측 알림 아이콘(미읽음 배지 카운트)
- **중상단 (히어로 영역)**: 좌측 카피 텍스트(메인 타이틀 + 서브 타이틀 + CTA 버튼) + 우측 일러스트 이미지 (대략 50:50)
- **본문**: 섹션 헤더 행("작업 목록" 텍스트 + 분석모델 필터 + 비교유형 필터 + 정렬 토글) + 카드 그리드 (반응형 1~5컬럼)

**표시 데이터**
- 헤더: 미읽음 알림 개수
- 히어로: 정적 카피 ("AI로 탐지하는 ...", "[도메인 자동 탐지]"), CTA 버튼 라벨
- 작업 카드 그리드 (각 카드 1건):
  - 작업 ID, 작업명, 작업 설명
  - 적용 분석모델 목록 (다중, 예: 건물·도로 → 일반화: 객체 카테고리 다중 태그)
  - 비교 유형 (영상-영상 / 수치지도-영상 → 일반화: 동종 비교 / 이종 비교)
  - 기준 데이터 촬영시점(년월), 비교 대상 데이터 촬영시점(년월) → 기간 배지
  - 작업 생성일자
  - 작업 상태 + 진행률 (%)
  - 썸네일 이미지 경로 (또는 더미)

**가능한 액션**
- 헤더 네비게이션 클릭 → 해당 라우트 이동
- 알림 벨 클릭 → 알림 다이얼로그 토글
- CTA 버튼 ("[분석 시작]") 클릭 → `/resources`로 이동
- 분석모델 필터 (드롭다운, 다중 선택): "모든 분석" / "건물 변화탐지" / "도로 변화탐지" 등
- 비교 유형 필터 (드롭다운, 다중 선택): "모든 비교" / "동종 비교" / "이종 비교"
- 정렬 토글 (날짜 오름/내림)
- 카드 클릭 → `/analyses/{id}` 이동

**상태 변화**
- 필터 변경 → 카드 그리드 즉시 재렌더 (클라이언트 측 필터)
- 정렬 토글 → 카드 순서 재정렬
- 알림 벨 클릭 → 다이얼로그 열림/닫힘 토글
- 진행 중인 작업의 진행률은 **백엔드 폴링/소켓**으로 실시간 갱신 (카드 내 진행바)
- 완료(100%) 카드는 메타정보·배지 풀세트 노출, 미완료 카드는 진행바만 노출

**다른 화면과의 연결**
- → `/analyses/{id}` (카드 클릭)
- → `/resources` (CTA 버튼)
- ← (없음, 진입점)

### 2.2 작업 목록 + 지도 (`/analyses`)

**사용자 목적**: 작업들이 어느 지역에 있는지 지도에서 공간적으로 파악하면서, 좌측 리스트에서 작업을 검색·필터·정렬하여 원하는 작업을 찾아 상세로 이동.

**레이아웃 영역** (좌측 사이드바 + 지도 분할, 사이드바 토글 가능)
- **상단 (헤더 띠)**: 전역 헤더와 동일 (사이드바 닫힘 시 전 폭, 열림 시 사이드바 폭만큼 줄어듦)
- **좌측 사이드바** (고정 폭, 약 340px):
  - 사이드바 상단 — 로고/버전 + 사이드바 닫기 토글
  - 검색 영역 — 텍스트 검색 입력 + "지도 영역으로 필터링" 토글 버튼
  - 필터·정렬 행 — 분석모델 필터 드롭다운 + 비교 유형 필터 드롭다운 + (필요 시) 클러스터 초기화 버튼 + 정렬 토글
  - 작업 카드 리스트 (세로 스크롤, 각 카드는 작은 사이즈)
  - 사이드바 하단 — 스크롤 가능 시 "맨 위로" 버튼 (고정)
- **우측 지도 영역**: 전체 베이스맵 + 작업 위치 클러스터/포인트 레이어 + 지도 컨트롤(우측 도구), 사이드바 닫힘 시 전 폭 확장

**표시 데이터**
- 사이드바 작업 카드 (각 카드):
  - 작업명, 설명
  - 분석모델 태그 (다중)
  - 비교 유형 태그
  - 두 데이터의 촬영 기간 배지 (YYYY.MM-YYYY.MM)
  - 작업 생성일시
  - 진행률 + 상태 (미완료 카드만)
- 지도 위:
  - 작업 위치 포인트 / 클러스터 (개수 라벨 포함)
  - 클러스터 클릭 시 해당 클러스터에 속한 작업 ID 집합

**가능한 액션**
- **검색**: 텍스트 입력 → 디바운스 후 클라이언트 필터 (작업명·설명 매칭)
- **지도 영역 필터링 토글**: 토글 ON → 지도에서 드래그 박스로 사각 영역 지정 → 해당 영역에 포함된 작업만 리스트에 표시. 토글 OFF 시 전체 복원.
- **분석모델 필터** (드롭다운 다중): 선택된 모델을 포함하는 작업만 표시
- **비교 유형 필터** (드롭다운 다중): 선택된 비교 유형의 작업만 표시
- **클러스터 초기화 버튼**: 클러스터 클릭으로 좁혀진 ID 집합을 해제해 전체 작업 다시 표시 (선택된 클러스터가 있을 때만 보임)
- **정렬 토글**: 날짜 오름/내림
- **카드 클릭**: 해당 작업 상세 (`/analyses/{id}`)로 이동
- **지도 줌/팬, 베이스맵 전환** (지도 컨트롤러)
- **지도 위 작업 포인트 클릭**: (구현 시) 카드 강조/이동
- **사이드바 토글 버튼**: 사이드바 펼침/접힘 (localStorage에 영구 저장)

**상태 변화**
- 검색·필터·정렬·클러스터 변경 → 카드 리스트 즉시 재렌더
- 사이드바 닫기 → 지도 전 폭 확장 (부드러운 슬라이드)
- 지도 영역 토글 닫기 → 박스 사라지고 bbox 필터 해제
- 카드 진행률은 폴링으로 실시간 갱신
- 화면 unmount 시 — 클러스터 ID 초기화, 지도 줌 리셋

**다른 화면과의 연결**
- → `/analyses/{id}` (카드 클릭, 또는 알림 클릭으로 직접 진입 가능)
- → `/resources`, `/` (헤더 네비게이션)

### 2.3 작업 상세 (`/analyses/:id`)  ← **이 시스템의 핵심 화면**

**사용자 목적**: 단일 작업의 변화탐지 결과를 (a) 두 시점 영상 비교 지도 위에서 시각적으로 검토하고, (b) 변화 객체(폴리곤) 단위로 속성·통계를 확인하며, (c) 신뢰도(확신도)·지역·카테고리 필터로 좁히고, (d) 잘못 탐지된 객체를 편집·삭제하거나 누락된 객체를 신규 생성하고, (e) 결과를 파일로 내보내고 리포트를 다운로드.

**레이아웃 영역** (좌측 사이드바 + 큰 지도 + 우측 슬라이드 인 패널, 3분할 가능)
- **상단**: 글로벌 헤더
- **좌측 사이드바** (약 340px, 토글):
  - 로고·버전 + 사이드바 닫기
  - 작업 헤더 (뒤로가기 화살표 + 작업명 + 설명 + 분석모델 태그들 + 생성일시 + ⋮ 더보기 버튼)
  - 더보기 메뉴 (팝오버) — "정보 수정", "분석 정보 삭제"
  - 본문 (스크롤): 아래 5개 아코디언 섹션 + 푸터 버튼
    - 아코디언 1: **지역 선택** (행정구역 2단 셀렉트)
    - 아코디언 2: **분석 데이터** (기준 데이터 + 비교 대상 데이터 가시성 토글)
    - 아코디언 3: **확신도** (이중 범위 슬라이더 + 도움말 툴팁)
    - 아코디언 4: **건물 변화** (객체 카테고리 1) — 4개 변화 유형 서브 아코디언
    - 아코디언 5: **도로 변화** (객체 카테고리 2) — 3개 변화 유형 서브 아코디언
    - 아코디언 6: **검수 히스토리** (편집 이력 표)
    - 푸터: "분석결과 내보내기" 버튼 + "리포트 보기" 버튼
- **중앙 (지도 영역)**:
  - 단일 모드 / 분할 비교 모드 / X축 스와이프 / Y축 스와이프 — 4개 뷰어 모드
  - 분할 모드: 좌(기준 영상) + 분할바(촬영시점 배지) + 우(비교 대상 영상)
  - 스와이프 모드: 단일 지도 위 OL 스와이프 컨트롤
  - 변화 객체 폴리곤 레이어 (변화 유형별 색)
  - 행정구역 경계 레이어 (시군구·읍면동)
  - 클릭/드래그/드로우/이동 인터랙션
- **지도 위 떠있는 도구바** (사이드바 토글 상태에 따라 위치 이동):
  - 좌측 그룹 — 뷰어 모드: 화면 2분할 / X 스와이프 / Y 스와이프
  - 중앙 그룹 — 편집 모드: 단일 폴리곤 선택 / 폴리곤 생성 / (폴리곤 이동, 비활성)
  - 우측 그룹 — 다중 선택 (드래그 박스로 폴리곤 선택 후 일괄 삭제)
- **지도 위 떠있는 정보 오버레이** (객체 선택 시):
  - 정보 카드 (드래그 가능): 탐지모델, ID, 변화유형, 확신도, 면적, 주소, 의견(있을 때)
  - 푸터: 삭제 / 폴리곤 수정 / 정보 수정
  - "정보 수정" 클릭 시 같은 위치에 편집 카드로 전환 (변화유형 select, 의견 textarea, 취소/적용)
  - "폴리곤 수정" 클릭 시 → 폴리곤 편집 모달 다이얼로그 (별도 지도 + 도구)
- **신규 생성 오버레이** (폴리곤 그리기 후 자동 표시): 탐지모델(선택 가능 시), 변화유형, 의견 입력 + 취소/적용
- **우측 슬라이드 인 패널 (리포트 보기)** (약 600px, 토글로 좁히기 가능):
  - 패널 토글 핸들 (좌측 가장자리)
  - 헤더: 위치 배지(선택된 행정구역명) + "리포트 다운로드" 버튼 + 닫기
  - 탭 (객체 카테고리별, 활성화 조건 충족 시): 건물변화 / 도로변화
  - 본문 (탭 컨텐츠 = "분석 결과"):
    - 헤더 행: "분석 결과" + 총 건수 / 총 면적
    - 기준 영상·대상 영상 파일명 박스 (배지+파일명)
    - 도넛 차트 (변화 유형별 건수 분포)
    - 통계 표 (AG Grid, 컬럼: 유형 / 검출면적 / 검출건수)
    - "지역별 분포" 누적 막대 차트
    - "상세목록" 헤더: 유형 셀렉트 (전체 또는 단일 유형) + 엑셀 다운로드 버튼
    - 페이지네이션 그리드 (AG Grid, 컬럼: 위치(클릭→이동) / ID / 주소 / 면적 / 유형, 페이지당 10건, 면적 내림차순)

**표시 데이터** (스키마)
- **작업 메타**:
  - id, name, description, models[], compare_type, status, rate
  - standard_resource (기준 데이터): id, display_name, type(영상|수치지도), taken_start_at, taken_end_at, bbox, path, tile_path
  - compare_resource (비교 대상): 동일 스키마
- **행정구역**: `sigungu` (시군구 코드·명) → `eupmyeondong` (읍면동 코드·명, sgg_cd 의존)
- **확신도 범위 값**: [최소(0~100), 최대(0~100)]
- **검출 객체 (Detection)** (단일 폴리곤):
  - id, model("building"|"road"), type(변화유형 코드 1~4), accuracy(0~100), area(㎡), address, wkt(폴리곤 텍스트), region_code(행정구역 코드, 앞 5자리=시군구·앞 8자리=읍면동), memo
- **객체 그룹 (DetectionObject)**: model + model_types[] (각: type, count, detections[])
- **변화유형 코드 매핑**:
  - 건물(building): `1=신축`, `2=소멸`, `3=갱신`, `4=색변화` → 일반화: 신규 / 소실 / 갱신 / 변형
  - 도로(road): `1=신설`, `2=소멸`, `3=갱신` → 일반화: 신규 / 소실 / 갱신 (도로는 색변화 없음)
- **검수 히스토리 (ObjectHistory)**: object_id, model_name, type, changes(변경구분: "삭제"|"수정" 등), memo, wkt
- **알림(Notification)**: id, comment, created_at, is_read, model, task_name, user_id, detection_task

**가능한 액션** (영역별)

지역 선택:
- 시군구 셀렉트 (옵션: 전체 + 작업에 포함된 시군구 목록)
- 읍면동 셀렉트 (시군구 선택 후 활성화)
- "전체" 선택 시 행정구역 필터 해제

분석 데이터 (체크박스 토글):
- 기준 데이터 가시성 ON/OFF (지도 레이어)
- 비교 대상 데이터 가시성 ON/OFF (지도 레이어)

확신도 슬라이더:
- 최소값 드래그 (0~100, 1단위), 최대값은 100 고정 (현 구현)
- 도움말 아이콘 호버 → 설명 툴팁

객체 카테고리 아코디언 (건물/도로 각각):
- 카테고리 마스터 체크박스 (전체 ON/OFF)
- 카테고리 마스터 펼침/접힘
- 각 변화 유형 서브 아코디언:
  - 유형별 체크박스 (지도 레이어 가시성)
  - 유형 펼침/접힘
  - 펼치면 해당 유형의 객체 미니 표 (위치 아이콘 / ID / 확신도 / 면적)
  - 표의 위치 아이콘 클릭 → 지도 해당 폴리곤 zoom & 선택

검수 히스토리 표:
- 행 클릭 (위치 아이콘) → 지도 이동 + 폴리곤 선택. "삭제" 이력의 경우 별도 마커 아이콘이 지도에 일정 시간 표시 (줌·이동 임계값 초과 시 자동 해제)

지도 도구바:
- 화면 2분할 / X 스와이프 / Y 스와이프 토글
- 단일 폴리곤 선택 토글 (편집 모드: select)
- 폴리곤 생성 토글 (draw 모드, 클릭하여 폴리곤 그리기)
- 다중 선택 토글 (drag-pointer, 박스로 폴리곤 일괄 선택 → 삭제 버튼 노출)
- (Undo/Redo 핸들러 정의는 있으나 현재 도구바에서는 노출 안 됨)

지도 컨트롤러 (우측 떠있음):
- 줌 인/아웃 버튼
- 거리(직선) 측정 토글
- 면적 측정 토글
- 베이스맵 전환 (항공 / 일반)

객체 선택 시 정보 오버레이:
- 드래그하여 위치 이동
- 닫기(×)
- 삭제 → 확인 다이얼로그 → 확정 시 삭제 토스트 + 데이터 새로고침
- 정보 수정 클릭 → 같은 카드 자리에서 편집 폼으로 전환 (유형 select + 의견 textarea, 의견 100자 제한 + 초과 시 토스트 경고) → 적용 또는 취소
- 폴리곤 수정 클릭 → 폴리곤 편집 모달 (separate 지도 다이얼로그):
  - 좌상 도구바 (단일 선택 / 폴리곤 정점 이동)
  - 우상 베이스맵 썸네일 그룹 (항공/일반 전환)
  - 지도 영역 (스와이프 토글 가능)
  - 푸터 — 취소(저장 안 함, 새로고침) / 저장 (변경 반영, 로딩 스피너)
  - 모달 닫기는 백드롭 클릭/ESC 차단됨, 전용 닫기 버튼만 동작

폴리곤 신규 생성 (도구바 → 폴리곤 생성 모드):
- 지도에서 클릭으로 폴리곤 그리기 → 자동으로 생성 오버레이 표시
- 탐지모델 선택 (모델이 다중일 때만 노출)
- 변화유형 선택 (모델에 따른 옵션 차등)
- 의견 입력 (textarea)
- 적용 → 생성 API 호출, 성공 토스트 / 실패 처리
- 취소 → 그린 폴리곤 제거, 오버레이 닫기

다중 선택 모드:
- 드래그 박스로 영역 내 폴리곤 일괄 선택
- 별도 "삭제" 버튼 노출 → 일괄 삭제

작업 헤더 ⋮ 더보기 메뉴:
- 정보 수정 (이름·설명 인라인 폼) → 저장 시 헤더 즉시 반영
- 분석 정보 삭제 (확인 다이얼로그) → 삭제 후 이전 화면으로 자동 복귀

푸터 버튼:
- 분석결과 내보내기 (다운로드 트리거; 형식·범위는 백엔드 책임)
- 리포트 보기 → 우측 슬라이드 인 패널 열림 (visible=true, open=true)

리포트 패널:
- 패널 핸들로 좁히기/펼치기 (visible 유지, open 토글)
- 우상단 닫기 → 패널 완전 닫기 (visible=false)
- 위치 배지: 현재 행정구역 필터 컨텍스트 표시
- 리포트 다운로드 (전체 결과 파일 받기)
- 탭 전환 (객체 카테고리별, 체크된 유형이 있을 때만 활성)
- 도넛 차트 hover → 툴팁
- 누적 막대 차트 — 행정구역(시군구)별 변화 유형 누적
- 상세목록 — 유형 필터 셀렉트, 엑셀 다운로드, 페이지네이션
- 그리드 셀(위치 컬럼) 클릭 → 지도 해당 좌표로 이동/줌

**상태 변화** (주요)
- 시군구 변경 → 읍면동 셀렉트 옵션 재로딩 + 자동으로 "전체" 리셋
- 행정구역 / 확신도 / 카테고리 체크 상태 변화 → **지도 폴리곤 레이어 즉시 재필터** + 우측 패널의 도넛/표/막대/상세목록 모두 재계산
- 객체 클릭 → 지도가 해당 폴리곤 bbox에 맞게 zoom & center, 정보 오버레이가 폴리곤 우하단에 위치, 편집 모드는 select로 강제
- 객체 정보/폴리곤 수정 후 → 작업 객체 데이터 새로고침
- 객체 삭제 후 → 데이터 새로고침 + 선택 초기화
- 폴리곤 신규 생성 후 → 객체 데이터 새로고침 + 그리기 모드 종료
- 모드 토글 (편집 모드들은 상호 배타) — 새 모드 선택 시 이전 모드 정리(`clear()`)
- 화면 unmount 시 — 확신도 [0,100] 리셋, 카테고리 체크 마스터 true 리셋, 선택된 객체 null, 분석 메타 비움, 지도 중심·줌 초기 위치 복귀

**다른 화면과의 연결**
- ← `/analyses` (카드 클릭) 또는 `/` (랜딩 카드 클릭) 또는 알림 클릭
- → 이전 페이지 (헤더 뒤로가기 화살표, 또는 작업 삭제 후)
- → `/resources`, `/analyses` (헤더 네비게이션)

### 2.4 리소스 목록 + 분석 생성 (`/resources`)

**사용자 목적**: 사용 가능한 입력 자원(영상/수치지도)을 지도와 연동하여 탐색하고, 두 자원(기준 + 비교 대상)을 선정하여 새 분석 작업을 생성·실행.

**레이아웃 영역** (작업 목록 화면과 유사한 사이드바 + 지도 구조 + 우상단 떠있는 분석 생성 패널)
- **상단**: 글로벌 헤더
- **좌측 사이드바** (약 340px, 토글):
  - 로고·버전 + 사이드바 닫기
  - 검색 영역 — 텍스트 검색 + 지도 영역 필터 토글
  - 카테고리 토글 행 — "영상" 토글 (개수 배지) + "수치지도" 토글 (개수 배지) + 클러스터 초기화 + 정렬 토글
  - 리소스 카드 무한 스크롤 리스트 (페이지당 8개, IntersectionObserver 자동 로드)
  - 하단 — 스크롤 가능 시 "맨 위로" 버튼
- **우측 지도**: 베이스맵 + 리소스 위치 클러스터/포인트 + 선택된 리소스의 타일 레이어(미리보기)
- **우상단 떠있는 패널 (분석 생성 위저드)**: 항상 노출, 사이드바 토글 따라 좌측 마진 변동
  - 헤더: 펼침/접힘 토글 + 초기화
  - 3단계 탭 (현재 단계만 활성, 다른 단계는 직접 클릭 비활성):
    - 1단계: 데이터 선택
    - 2단계: 분석모델 선택
    - 3단계: 내용 입력

**표시 데이터**

리소스 카드:
- resource_id, resource_type ("image"=영상 / "digital"=수치지도 → 일반화: 동적 자원 / 정적 자원), resource_platform (예: 위성/드론/항공 등), resource_display_name (파일명), resource_taken_start_at (촬영일/제작일), resource_taken_end_at, mapindexes[] (도엽 코드 배열), resource_path, resource_tile_path
- 카운트 (헤더): 영상 N개 / 수치지도 N개 (필터 결과 기준)
- 페이지네이션 메타: page, last_page

분석 생성 위저드:
- 1단계: standard_resource_id {id, label}, compare_resource_id {id, label}, standard_resource_type, compare_resource_type, 중첩률(%) 또는 로딩 상태
- 2단계: selectedModels[] (예: "건물 변화탐지" / "도로 변화탐지" — 다중 선택 가능)
- 3단계: analysisName (분석명, 기본값=비교 대상 파일명에서 자동 추출), description (설명)

**가능한 액션**

리소스 패널:
- 검색 (텍스트, 디바운스, 백엔드 query param)
- 지도 영역 필터 토글 (드래그 박스로 bbox 한정)
- 카테고리 토글 (영상 / 수치지도 — 둘 다 OFF면 전체 표시)
- 정렬 토글 (날짜 오름/내림)
- 클러스터 초기화 (지도 클러스터 클릭으로 좁혀진 ID 해제)
- 리소스 카드 클릭 → 카드 선택 상태 + 지도가 해당 리소스 bbox로 이동 + 타일 레이어 표시
- 카드 선택 후 카드 안에 "기준 데이터" / "대상 데이터" 두 버튼 노출:
  - "기준 데이터" 클릭 → standard_resource_id에 등록 (이미 비교 대상으로 등록된 리소스는 비활성)
  - "대상 데이터" 클릭 → compare_resource_id에 등록 (반대로도 동일)
- 도엽 코드 다수 표시 시 호버 → 전체 목록 툴팁
- 무한 스크롤 (하단 sentinel 진입 시 다음 페이지 로드, isLoading 가드)
- 검색·정렬·필터 변경 시 → 페이지 1로 리셋, 누적 리스트 비우고 재로딩
- (분석 생성 위저드 활성 탭 ≥ 1일 때 카드 전체 비활성화 — 데이터 선택 외 액션 봉쇄)

분석 생성 위저드:
- 헤더 토글 → 패널 폭 축소/확장 + 본문 숨김
- 헤더 초기화 → 모든 입력값 리셋, 1단계로 복귀
- 1단계:
  - 기준/대상 자원 두 입력 박스 (좌측 카드에서 선택한 값 자동 채워짐)
  - 두 자원 모두 선택되면 → 중첩률 자동 계산 (로딩 메시지 → 결과). 단, "수치지도(기준) × 영상(대상)" 조합은 중첩률 검사 스킵.
  - 중첩률 계산 결과 0(중복 영역 없음) → 알럿 다이얼로그 → 확인 시 두 선택 모두 리셋
  - "다음" 버튼 (두 자원 + 중첩률 준비 완료 시 활성)
- 2단계:
  - 분석모델 체크리스트 (객체 카테고리 다중 선택 가능)
  - "이전" / "다음" (1개 이상 선택 시 활성)
- 3단계:
  - 분석명 입력 (placeholder = 자동 추출된 비교 대상 파일명)
  - 설명 입력 (textarea)
  - "이전" / "분석 실행"
  - 분석 실행 → 작업 생성 API → 성공 시 confirm 다이얼로그 ("분석 요청 완료. 작업 목록으로 이동?") → 확인 시 `/analyses` 이동, 어느 쪽이든 폼 리셋

**상태 변화**
- 검색·정렬·필터·bbox·클러스터 변경 → 페이지 리셋 + 데이터 재로딩
- 카드 선택 → 지도 이동 + 타일 레이어 즉시 표시 (선택 해제 시 제거)
- 한 카드를 "기준"으로 등록하면 같은 카드에서 "대상" 버튼은 비활성 (역도 동일)
- 자원 선택 변경 → 중첩률 자동 재계산 (또는 스킵 룰 적용)
- 위저드 활성 탭 변경 → 사이드바 카드 클릭 가능 여부 토글
- 화면 unmount 시 — 클러스터 초기화, 영역 토글 OFF, 선택 리셋

**다른 화면과의 연결**
- ← `/` (CTA), `/analyses` (헤더 네비)
- → `/analyses` (분석 실행 후 confirm 시) 또는 `/analyses/{새 작업 id}` (간접 — 목록에서 클릭)

## 3. 공통 인터랙션 패턴

### 3.1 검색
- 좌측 사이드바 상단의 단일 검색 입력 (텍스트). 입력 즉시 또는 디바운스 후 클라이언트 또는 서버에 쿼리 전달.
- 작업 목록·리소스 목록 화면 동일 패턴.

### 3.2 필터
- **드롭다운 멀티선택 필터**: 분석모델 / 비교 유형 (체크 가능, "모든 X" 옵션 포함). 변경 시 즉시 리스트 재렌더.
- **카테고리 토글 버튼**: 리소스 화면의 영상/수치지도 (둘 다 OFF = 전체).
- **지도 bbox 필터**: 토글 ON → 드래그 박스로 영역 지정 → 해당 영역에 포함된 항목만 리스트에 표시.
- **공간 클러스터 클릭 필터**: 클러스터 클릭 → 클러스터 내 항목 ID 집합으로 좁힘. "초기화" 버튼으로 해제.
- **확신도 범위 슬라이더**: 작업 상세 화면에서 값(0~100)을 변경하면 모든 의존 컴포넌트(지도 폴리곤, 통계, 카운트, 리포트)가 즉시 재계산.
- **체크박스 트리**: 객체 카테고리 마스터 + 각 변화 유형 자식 (가시성·집계 모두 영향).
- **계층형 셀렉트**: 시군구 → 읍면동 (상위 변경 시 하위 자동 리셋).

### 3.3 정렬
- 단일 정렬 토글 버튼 ("날짜순"). 클릭 시 ASC/DESC 토글.
- 정렬 기준은 1축만 제공 (다축 정렬 없음).

### 3.4 페이지네이션 / 무한 스크롤
- **리소스 목록**: IntersectionObserver 기반 무한 스크롤 (페이지당 8건). 하단 sentinel 요소가 뷰포트 진입 시 다음 페이지 로드, 로딩 중 가드.
- **상세 그리드 (작업 상세 우측 패널)**: 명시적 페이지 번호 페이지네이션 (페이지당 10건, 첫·이전·다음·끝 버튼). 페이지 상태는 store에 보관.

### 3.5 모달 / 다이얼로그 / 오버레이 (3종 패턴)
- **확인 다이얼로그 (AlertDialog)**: 중요한 상태 변경(삭제·중복 알림 등) 확인. 취소·확정 두 버튼.
- **편집 모달**: 폴리곤 수정 다이얼로그. 백드롭 클릭/ESC 닫기 차단, 전용 닫기 버튼만.
- **지도 위 떠있는 카드 오버레이**: 객체 정보·편집·생성. 드래그 가능, 위치는 폴리곤 기준점에 anchor.

### 3.6 토스트 알림
- 짧은 작업 결과 피드백 (성공·실패·경고). 메모 100자 초과 같은 인라인 검증도 토스트로 통보.

### 3.7 토글 사이드바
- 좌측 사이드바는 모든 페이지에서 토글 가능 (Expand 아이콘). 상태는 localStorage에 영구화. 닫힘 시 지도/콘텐츠 영역이 좌측으로 확장.

### 3.8 슬라이드 인 우측 패널
- 작업 상세에서 "리포트 보기" 클릭 시 우측에서 슬라이드 인. 핸들로 좁히기/펼치기 가능, 명시적 닫기로 완전 닫음.

### 3.9 알림 (글로벌)
- 헤더 알림 벨 → 미읽음 카운트 배지. 클릭 → 알림 다이얼로그 (목록).
- 알림 항목 클릭 → 해당 작업 상세로 이동 + 읽음 처리.
- 항목 삭제 가능, 삭제 후 카운트 즉시 재계산.

### 3.10 진행률 폴링
- 작업 카드의 진행률은 백엔드 폴링 또는 WebSocket으로 갱신. 100% 미만 카드는 진행바만, 100% 카드는 메타정보 풀세트 표시.

### 3.11 비동기 액션 로딩 표시
- 자원 중첩률 계산, 폴리곤 저장, 객체 삭제 등은 버튼 비활성 + 인라인 메시지 또는 로딩 스피너로 표시.

### 3.12 지도 인터랙션 (공통)
- 줌 +/−, 거리 측정, 면적 측정, 베이스맵 전환(항공/일반)이 모든 지도 화면에서 동일하게 제공.
- 드래그 박스, 폴리곤 그리기, 단일/다중 선택, 폴리곤 편집은 작업 상세에서만.

## 4. 데이터 흐름 (사용자 관점)

### 4.1 작업 생성 흐름 (Resource Selection → Task Creation)
1. `/resources` 진입 → 리소스 목록·카운트 로드
2. 사용자가 검색/필터/지도 영역으로 후보 리소스 좁힘
3. 카드 클릭 → 지도가 해당 리소스 영역으로 이동 + 타일 미리보기
4. 카드 안 버튼으로 "기준 데이터" 또는 "대상 데이터" 등록 → 위저드 1단계에 자동 입력
5. 두 자원 등록되면 중첩률이 자동 계산되어 표시 (또는 스킵 룰)
6. 중첩이 없으면 알럿 → 자원 리셋
7. 중첩 충분하면 1→2단계, 분석모델(객체 카테고리) 다중 선택 → 2→3단계
8. 분석명·설명 입력 → "분석 실행" → 작업 생성 → 확인 시 `/analyses`로 이동

### 4.2 작업 결과 검토·검수 흐름
1. `/analyses` 또는 `/`에서 작업 카드 클릭 → `/analyses/:id`
2. 좌측 사이드바에서 행정구역·확신도·카테고리·유형 필터 적용
3. 지도 모드 선택 (분할/스와이프) + 기준·대상 데이터 가시성 토글 → 시각 비교
4. 변화 유형별 미니 표에서 위치 아이콘 클릭 → 지도가 폴리곤으로 zoom + 정보 오버레이 표시
5. 정보 확인 후:
   - **편집** → 정보 수정 (유형·의견) 또는 폴리곤 수정 (모달에서 정점 편집)
   - **삭제** → 확인 → 삭제
   - **신규 추가** → 도구바 폴리곤 그리기 → 그리기 완료 시 생성 오버레이 → 메타 입력 → 적용
   - **다중 삭제** → 드래그 박스로 선택 → 일괄 삭제 버튼
6. "리포트 보기" → 우측 패널에서 도넛/통계/막대/상세목록 검토
7. "엑셀 다운로드" / "리포트 다운로드" / "분석결과 내보내기" 중 필요한 출력 받기
8. 검수 이력은 좌측 사이드바 "검수 히스토리" 아코디언에서 사후 조회

### 4.3 필터 ↔ 시각화 ↔ 통계 동기화
중요한 흐름: 좌측 사이드바의 모든 필터(지역 + 확신도 + 카테고리/유형 체크)는 단일 진실 원천 (Zustand store) 으로서 다음 모두에 동시 영향:
- 지도 폴리곤 레이어 가시성·필터링
- 좌측 사이드바 카운트 표시
- 우측 리포트 패널의 도넛/통계표/누적막대/상세목록 (모두 같은 필터를 거친 결과)

### 4.4 알림 흐름
- 백엔드 → 헤더 알림 벨로 새 알림 푸시 (소켓 또는 폴링)
- 미읽음 배지 카운트 표시 → 사용자 클릭으로 다이얼로그 열기
- 항목 클릭 → 해당 작업 상세로 이동 + 읽음 처리

### 4.5 화면 간 데이터 전달
- 라우트 파라미터 (`:id`) 외에는 전역 store/localStorage 사용:
  - 사이드바 토글 상태 → localStorage
  - 분석 생성 위저드 입력 → Zustand store (페이지 이동 시에도 유지)
  - 지도 view (center/zoom) → 전역 view store
- 작업 상세 페이지의 모든 상호작용 상태(편집모드, 선택객체, 모드 등)는 페이지 unmount 시 명시적으로 초기화.

## 5. 권한·역할 구분

코드 분석 결과, **명시적인 권한·역할 분기 로직이 발견되지 않음**. 사용자별 메뉴 차등 표시, 액션 차단 분기, 역할 기반 라우팅 등 모두 없음. 알림 데이터에 `user_id` 필드가 존재하지만, 현재 UI에서 권한별 분기에 사용되지 않음.

→ **변화탐지 플랫폼에서 권한·역할이 필요하다면 본 시스템 명세에서는 도출되지 않으며, 별도로 설계해야 함.**

## 6. 이 시스템 기능의 핵심 구조 (요약)

이 시스템은 **"입력 자원 → 분석 작업 → 결과 검토·검수 → 출력"** 의 4단계 파이프라인을 4개 화면(랜딩 / 작업 목록 / 작업 상세 / 리소스 목록)에 매핑한 단방향 워크플로우 시스템이다. 핵심은 **단일 작업 상세 화면에 모든 검수 활동을 집중**시킨 구조로, 좌측 필터 사이드바·중앙 다중모드 지도(분할/스와이프 + 4종 편집 도구)·우측 슬라이드인 리포트 패널의 3분할 위에서 사용자가 지역·신뢰도·카테고리·유형 필터를 좁히면 지도 폴리곤·통계·차트·상세목록이 모두 단일 store를 통해 즉시 동기화된다. 객체 단위 인터랙션은 **선택 → 정보 오버레이 → 편집/삭제/생성**의 3단 흐름을 지도 위 떠있는 카드로 일관되게 처리하며, 폴리곤 정점 편집만 별도의 전체화면 모달로 분리해 작업 안전성을 확보한다. 새 작업 생성은 리소스 화면에서 **카드 선택 → 비교 쌍 등록 → 3단계 탭 위저드(데이터/모델/메타) → 중첩률 자동 검증 → 실행** 순서로 가이드되며, 모든 화면이 OpenLayers 지도를 공통 기반으로 두고 검색·필터·정렬·bbox·클러스터·무한스크롤 같은 일반화된 데이터 탐색 패턴을 페이지마다 동일하게 재사용한다.
